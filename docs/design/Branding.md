# TrophyTracker visual identity

This document describes the visual system and the runtime artwork, both
derived from the [reviewed UI proposal](ui-proposal-reviewed.html) and the
[desktop revamp roadmap](../planning/DevelopmentRoadmap.md#active-desktop-plan--interface-revamp-r16r27).
Decision D1 selected concept A for small sizes and C for large ones.

## Visual system (R17)

The application theme follows the reviewed proposal: dark purple surfaces,
gold for achievements, progress and primary actions, turquoise for secondary
highlights and keyboard focus.

- **Tokens:** `src/retrocheevos/gui/styles.py` defines semantic color,
  typography, shape, size and spacing tokens and the application stylesheet.
  Older color names (`BG`, `LINK`, ...) are aliases kept until each screen is
  converted.
- **Components:** `src/retrocheevos/gui/components.py` provides buttons
  (primary, secondary, ghost, danger; regular and compact), filter chips,
  sidebar items, search fields, per-mode progress, metric cards, game cards,
  achievement rows and status pills. Large grids paint with delegates that use
  the same tokens instead of one widget per item.
- **Preview:** `tools/preview/component_preview.py` shows every component state,
  the tokens with their contrast ratios and the brand size comparison.
- **Contrast adjustments:** the reference outline `#3A3555` reaches only
  1.5:1 against panels, so interactive control borders use the derived
  `OUTLINE_CONTROL` (`#726A99`, 3.4:1 on panels). The reference outline remains
  for decorative dividers. Text tokens reach at least 4.8:1 on every surface;
  `tests/gui/test_visual_system.py` enforces the thresholds.
- **Fonts:** Inter (Regular, Medium, SemiBold, Bold; v4.1) for interface text
  and Space Grotesk (Medium, Bold; upstream commit `03507d0`) for headings,
  metrics and branding. Both are under the SIL Open Font License 1.1; the
  files and license texts live in `assets/fonts/` and are bundled with the
  application. If a font cannot load, the stylesheet falls back to Noto Sans or
  Segoe UI.

## Brand exploration

Vector copies of concepts A, B and C and the wordmark are in
[brand-exploration/](brand-exploration/README.md). The preview's brand sheet
renders them at 16, 24, 32, 48, 64 and 128 px on dark and light taskbar
backgrounds. First observation on Linux: at 16 px, concept A remains
recognizable while C's trophy becomes too small to read; at 48 px and above
both work.

**Decision D1 (2026-11-20):** concept A is the application icon wherever the
system draws it: window, taskbar, tray, launcher and AppImage icon, with a
tighter variant (less padding, larger trophy) for 16–24 px. Concept C is the
illustrative variant for large artwork, 128 px and up: onboarding, About and
release pages. Both share A's trophy geometry, and the wordmark keeps it too.
Concept B is not used.

**Revision (2026-11-21):** the maintainer preferred no dark tile behind the
trophy. Icon A now has a transparent background and a dark pixel outline
around the trophy. On a native Windows 11 taskbar at 125% scaling (icons drawn
at 30 px, title bar at 20 px), both the tiled and the outlined versions stayed
legible on dark and light themes; on the light taskbar the outline provides
the contrast the tile used to.

## Runtime artwork

All files are generated by `tools/brand/generate_icons.py` from the D1
concepts; rerun it after changing a concept or the palette:

```bash
QT_QPA_PLATFORM=offscreen PYTHONPATH=src .venv/bin/python tools/brand/generate_icons.py
```

| File | Content | Use |
| --- | --- | --- |
| `assets/icons/trophytracker-{16,24,32,48,64,128,256}.png` | Concept A | Window, taskbar and tray icon sizes, bundled |
| `assets/icon.png` (512 px) | Concept A | Desktop and AppImage icon, Windows executable icon, fallback for missing sizes |
| `assets/logo.png` (128 px) | Concept A | Former header emblem; kept for release artwork. The sidebar (R18) uses the 32 px icon, with the 64 px one on high-density displays |
| `assets/brand/illustration-c-512.png` | Concept C | Large artwork: onboarding (R24), About, release pages; not bundled yet |
| `assets/brand/wordmark-800.png` | Wordmark | Release artwork (R27); not bundled. The sidebar sets the name as live Space Grotesk text next to icon A |

**Rules for concept A.** The trophy is a pixel grid and is always drawn at an
integer number of pixels per grid unit, never resampled, so it stays sharp.
The background is transparent. A dark outline of a whole number of pixels
(1 px at 16–24 px, 2 px at 32–64 px, then about 1/30 of the size) follows the
trophy's silhouette, and the trophy with its outline fills about 70–85% of the
canvas. The trophy is `ACCENT_GOLD`; the outline, the cup opening and the gaps
inside the handles are `SURFACE_APP`, so the icon reads on both dark and light
taskbars.

**Rules for concept C.** Use only at 128 px and above. Its trophy uses the same
geometry as A.

The vector sources are in [brand-exploration/](brand-exploration/README.md).
All artwork is original to this project; the only third-party design assets
are the Inter and Space Grotesk fonts (SIL Open Font License 1.1).

## Retired artwork

The pre-revamp emblem (R-shaped controller with an achievement check and coral
sparkle, mint `#6ce7c4` and coral `#ff957f`) was replaced by concept A. It
remains in the git history and as the historical source
`assets/reference/retrocheevos-logo.jpeg` (not bundled). The
[historical Retrocheevos 1.1.0 Home preview](previews/home-1.1.0.png) uses
fictional account and progress data.

It was generated with the built-in `image_gen` tool by iterative image editing.
The final prompt was:

> Finalize this same R/controller/checkmark/coral-spark emblem as an opaque desktop app icon. Replace ALL transparent regions and ALL black regions, including the controller's negative-space opening and surrounding canvas, with a single perfectly uniform solid dark ink background #101826. This opaque solid background is essential; there must be no transparency anywhere. Clean all speckled edge artifacts. Keep the emblem the same recognizable design but scale the whole emblem to 74 percent of the square so it has comfortable even margins. Use clean solid mint #6CE7C4 for the R and controls and solid coral #FF957F for the check and sparkle, no texture, grain, gradients, glow or shading. Smooth crisp vector-style edges. Flat premium app icon on a plain dark square. No text, no other objects, no mockup, no drop shadow. Square 1024x1024.
